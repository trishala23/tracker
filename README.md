# Interview Prep Tracker

A checklist tracker for the 33-day (Sep 28 → Oct 30) Java Backend + DevOps interview plan, with per-day, per-phase, per-topic and overall percentages.

- **`plan.js`** – the plan data (phases, days, topic checklists). Edit it to change the plan.
- **`index.html`** – the tracker UI. No build step.

Progress and notes are stored in your browser's localStorage. Use **Export / Import** to move progress between devices.

## Publish on GitHub Pages

1. Repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Push (or run the *Deploy to GitHub Pages* workflow manually). The site appears at `https://<user>.github.io/tracker/`.
